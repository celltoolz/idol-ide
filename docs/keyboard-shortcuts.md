## Debugger

| Action | Shortcut |
|---|---|
| Debug file / Continue | F5 |
| Run file in terminal (no debugger) | Ctrl+F5 |
| Step over | F10 |
| Step into | F11 |
| Step out | Shift+F11 |
| Stop debugger | Shift+F5 |

**F10 is shared.** While a debug session is live it steps over; the rest of the
time it toggles Zen Mode. You are not reaching for a distraction-free layout
mid-step, so the two never compete in practice.

## Designer

| Action | Shortcut |
|---|---|
| Generate Code | Ctrl+Shift+B |
| Undo | Ctrl+Z |
| Redo | Ctrl+Y |
| Copy widget(s) | Ctrl+C |
| Paste widget(s) | Ctrl+V |
| Delete widget(s) | Delete |
| Nudge widget(s) | Arrow keys — 8px with snap on, 1px with snap off |
| Fine / coarse nudge | Shift+arrow — **inverts** the snap setting for that press |
| Select all widgets | Ctrl+A |
| Toggle tab order badges | ⇥ toolbar button |
| Grid nudge 1px (vs 8px) | Shift+click H/V nudge buttons |

**Shift inverts snap, it doesn't just disable it.** With snap on, Shift+arrow
gives you the 1px fine nudge; with snap **off**, Shift+arrow steps the full 8px
grid instead. Same rule as holding Shift while dragging, resizing, or drawing a
widget — the modifier means "the other mode", so whichever one you have set,
Shift is always the way to reach the other without leaving the keyboard.
